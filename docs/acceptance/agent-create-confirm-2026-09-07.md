# 创建智能体确认与手动发送验收

## 变更与边界

个人与业务智能体的一句话入口均改为“确定”。确认仅创建原生 `standard` 配置会话、校验工具范围、准备创建上下文，并通过宿主输入框服务填入需求。用户可修改内容，手动发送后才调用模型；确认不保存智能体。

变更属于 `@paimind/agent-market` 的既有创建入口；复用 `@paimind/agent-builder` 的上下文与封锁服务，以及 Harness（宿主）的会话和输入框。没有新增插件、持久化状态或工具调用接口。已导出的 `author` 保持显式提交契约，创建按钮不再调用它。手动发送之后的原生轮次监听与结构化草稿交接继续复用。
