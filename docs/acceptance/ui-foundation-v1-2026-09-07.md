## 2. 已完成的改动与问题

| 内容 | 所有者与结果 |
| --- | --- |
| 统一核心定义 | `ui-foundation` 增量提供语义间距、字阶、控件、输入、单选卡、状态、焦点及统一动效解析；保留原有公开入口 |
| 用户动效选择 | `visual-experience` 在自己的宿主设置中保存 `system/on/off`，默认跟随系统；即时生效、失败回读、并发写保护和释放后忽略迟到结果 |
| 真实设置入口 | `user-settings` 提供可选原生子插槽，视觉插件提供自己的内容与写入；协作偏好开关独立，界面字段不进入模型上下文 |
| 最小消费者 | 视觉插件拥有的过渡、个性化控件与预览、真实状态球共同消费核心规则；其余插件按后续顺序迁移 |
| 设置按钮语言缺陷 | 基线中页面切成英文后，按钮可访问名称仍为“设置”。迁入 `harness-compat` 统一适配，验证中英文同步、原生名称保留与清理 |
| 基线测试错误 | 模板物化测试预期包含未随仓库交付的 `docs/outputs` 空目录。依据起点文件树和模板说明修正预期，未更改模板文件或不可变组合包 |

状态球功能启停与是否播放动画继续是不同设置。关闭动效后保留状态文字及静态画面；生成内容中的动画、视频以及未接入的第三方动效保持原行为。

新增依赖仅为三个客户端对已有内部 `@paimind/ui-foundation` 的依赖及类型引用；未增加外部生产依赖。旧视觉设置调用方允许缺省 `motion`，读取时按默认值规范化。原设置按钮适配公开导出保留转导出。

受保护接口快照按本轮实际变化审阅后定向更新：核心包增加动效声明，兼容层增加适配函数，视觉设置增加可选字段与控制器方法，个性化增加可选贡献属性。其余受影响包仅有共享代码导致的构建哈希变化；包入口契约和运行时导出数量未变。没有批量接纳无关接口漂移。

## 4. 真实浏览器结果

| 场景 | 操作与观察 |
| --- | --- |
| 三态与持久化 | 点击关闭后权威文件为 `off`，根投影为关闭，预览动画为 `none`、控件过渡为 `0s`；开启后预览恢复 `1.8s` 动画；刷新、重新打开与独立宿主重启保留选择 |
| 键盘 | 原生单选方向键切换，焦点轮廓可见；从关闭继续切换到跟随系统，选择与实际生效值一致 |
| 协作偏好独立 | 协作开关关闭时仍可切换和保存动效；随后恢复协作开关，不覆盖动效值 |
| 模式独立 | 切到原生视觉模式，动效选择保留；切回品牌模式，只有一组界面偏好 |
| 来源缺席 | 最小组合关闭个性化来源并重启，界面偏好回到通用设置；关闭视觉来源并重启，界面偏好和动效投影消失、协作偏好仍可用；恢复后持久化的关闭值与单一入口恢复 |
| 样式与响应式 | 实际尺寸 1512×982、1280×720、900×720、390×844；900 和 390 的页面宽度未横向溢出；窄屏选项纵向排列、内容可滚动 |
| 主题与语言 | 桌面浅／深色与系统主题、390 浅／深／系统主题；中英文页面和设置名称切换；系统主题测试时操作系统实际为浅色 |
| 真实画布消费者 | 用既有显式预览入口渲染真正的状态球组件。关闭时两次分开截图哈希相同，开启时不同；状态均保留 `solving`。这是组件动效验证，不是模型任务执行证据 |
| 控制台 | 主实例仅观察到人为重启期间两条连接重试警告；辅助实例本轮读取的警告／错误为空。未采集完整网络请求瀑布，因此不声称全网络零错误 |

来源缺席浏览器场景采用修改本轮辅助宿主配置后冷启动；原位释放与事件清理由定向测试验证，未声称浏览器中完成所有热卸载排列。另有真实组合脚本覆盖实际安装移除。

### 仍未验收

- 未改变系统级明暗／减少动效设置，也未在浏览器模拟其实时变化。动效解析及系统变化事件由测试覆盖；系统主题随真实系统明暗变化的浏览器矩阵留待后续。
- 未配置模型或调用外部服务。协作设置 → 模型上下文 → 回复、真实运行状态球以及各业务插件的创建、安装、生成和执行链路均不计入本轮通过范围。
- 原生工作区目录选择器无法由本轮可用浏览器控制接口操作；已取消本任务发起的选择器并恢复页面。专属空目录未注册，无文件任务执行。这是验收限制，未推定为产品缺陷。
- 本轮未建设新的通用浮层管理器，也未验收跨插件嵌套弹层、审批和长任务组合。共享控件接入不代表相关业务插件已经完成迁移。
