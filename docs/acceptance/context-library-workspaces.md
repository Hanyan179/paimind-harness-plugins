## 明确的验证限制

- 文档及幻灯片已实际打印为 PDF（便携文档）并逐页核对。原生打印对话框的点击保存操作两次被前台浏览器操作打断，因此文件内容与版面通过无界面打印验证，原生对话框交互未完成自动化验收。
- 本轮使用空文件夹路径输入完成采用；原生操作系统目录选择窗口未完成自动化验收。
- 开发过程中修改尚未发布的内置模板说明，导致早期合成工作区的旧摘要与开发目录不一致；既有安全检查正确拒绝该旧回执。最终文档模板已重新采用并验证。没有修改已发布旧模板版本，也没有重写用户工作区回执来跳过检查。
- 内嵌浏览器未稳定触发下载，故下载核对改用标准浏览器。输入焦点也曾受到其他操作影响；无关输入未提交为模型任务，证据不记录该内容。
- 日常主工作副本存在其他任务的未提交改动，含共享接口快照、兼容包、品牌和连接中心；本分支不覆盖、不暂存或混入这些修改。合回与日常服务切换须在这些改动被妥善整理后进行。本轮不包含生产发布。
