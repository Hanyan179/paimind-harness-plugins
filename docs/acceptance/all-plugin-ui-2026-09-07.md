## 核心定义与公开接口

- 基座增加局部标签组键盘处理、共享开关和循环动效次数变量；关闭动效时过渡时长和循环次数为 0，保留状态文字。浏览器验证后恢复开启动效。
- 14 个此前未直接消费核心包的客户端补齐依赖及类型引用。不会把业务实体、持久化、网络或运行时状态移入核心包。
- 显示名称、技能分类和标签作为可选远程字段透传，原有规范身份、目录内容及摘要保持原值。缺席系统能力的历史偏好不会被静默删除。
- 公共变化包括基座键盘函数、兼容层设置滚动与动态样式归属函数、智能体策略的可选刷新接口，以及文档预览可选语言参数。无导出路径删除、公共契约版本重置或持久化字段改名。
- 受保护快照按已审查包逐项更新。运行文件摘要反映文案、样式与共享依赖内容；部分声明摘要变化来自导出样式常量的字面量类型。保留其他包的既有基线，不整份重置。完整差异保存在本机证据目录。
