# RQ-109 工作区模板中心验收

## 验收口径

本文件区分自动验证、真实宿主验证和浏览器业务验收。单元测试、类型检查或接口成功均不能单独代表功能已经完成验收。

## 自动验证

- [x] 内置与个人模板清单可读取；文件夹、元数据和确定组合共同决定稳定的包摘要。
- [x] 纯文件夹模板在没有 Agent 和 Skill 绑定时仍是完整合法模板。
- [x] 用户只能从 Harness 权威工作区身份发布模板；任意来源路径、敏感文件、符号链接、设备文件和目录逃逸均被拒绝。
- [x] 个人模板可浏览多层目录，可增加文件与子文件夹、编辑文本、删除文件或目录。
- [x] 已发布版本不可覆盖；每次文件或组合修改生成新补丁版本，旧版本保持不变，并用 `expectedDigest` 检查并发冲突。
- [x] 模板不保存“推荐能力”；Agent 与 Business Skill 都是作者明确保存的精确引用。
- [x] 物化在已注册的空工作区中原子完成，并写入来源与组合回执；未知、非空或已有 Session 的工作区拒绝物化。
- [x] 工作区 Business Skill 经过用户启用门禁、安装摘要校验与名称冲突检查后，合并进普通和 Agent Session 的有效目录。
- [x] 工作区绑定不会修改用户默认 Skill Policy、Session 临时选择或 Agent Profile；未绑定的工作区不会得到额外业务技能。
- [x] 远程接口使用严格输入与输出结构，调用方不能传入 Blueprint 服务端直接读写的任意本地路径。
- [x] 模板中心覆盖加载与重试、搜索、分类、内置/个人模板、目录详情、发布、编辑、取消、错误和成功状态。
- [x] 来源中心的 `ready`、`unavailable`、`error` 与真实空选项明确区分；中文界面不会泄露未知远程错误原文及其中携带的绝对路径。
- [ ] 并发冲突和物化警告确认仍需补充真实浏览器状态验收；底层失败关闭与串行化已有自动测试。
- [x] 带绑定模板在 Agent 或 Skill 缺失、停用或摘要/配置版本不一致时失败关闭；纯文件夹模板不依赖这两个中心。

## 真实 Harness 验收

- [x] 新包可通过正式组合安装并启动。
- [x] 原生侧边栏出现工作区模板中心入口，关闭后恢复原会话界面。
- [x] 用户可选择本地文件夹发布个人模板，或从已注册工作区发布，并在模板中心继续编辑形成新版本。
- [x] 选择空文件夹采用模板后，新工作区只由 Harness 注册并出现在原生工作区列表。
- [x] 三套内置模板至少各完成一次真实物化抽查，目录和内容与模板版本一致。
- [x] 带 Agent 绑定的模板会为采用流程创建的入口 Session 选择并绑定精确 Agent。
- [x] 带 Business Skill 绑定的模板在该工作区的新 Session 中可发现且只出现一次；其他工作区不会得到该 Skill。
- [x] 刷新浏览器及重启宿主后，工作区、文件与组合回执仍存在，工作区 Skill 作用域仍可解析。
- [x] 选择非空文件夹时可见失败原因，目录没有被覆盖。
- [ ] 卸载模板插件后，既有工作区、文件与会话不受影响；模板组合能力停止提供且不留下影子 Runtime。

## 浏览器业务验收

- [x] 桌面宽度下可完成发现、预览、文件夹导入、发布、编辑、采用和进入会话的完整流程。
- [x] 760 × 900 窄屏下模板列表、目录树、文本编辑器和组合配置仍可操作。
- [x] 关闭按钮位于模板中心右上角，键盘焦点和无障碍名称可用。
- [x] 界面明确表达“文件夹是主体，Agent/Skill 是可选确定编排”，没有推荐能力文案。
- [x] 界面明确说明 Business Skill 随工作区生效；在宿主提供稳定工作区默认 Preset 钩子前，Agent 只绑定采用流程创建的入口 Session。
- [x] 原生文件夹选择取消和非空目录部分失败均不会留下假成功，原文件内容及摘要保持不变。
- [x] 搜索无匹配结果时，真实浏览器明确显示零结果与空状态；清空搜索和关闭中心后恢复原会话界面。
- [ ] 加载、并发冲突、物化警告确认和创建中状态仍需补充完整的真实浏览器状态验收。
