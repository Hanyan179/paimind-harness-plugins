## 功能与边界

| 对象 | 唯一所有者与实现 |
| --- | --- |
| 连接配置、归属、管理页面 | `@paimind/mcp-center`，私有原子配置文件、版本冲突校验；归属、存储、执行位置分别有接口 |
| 助手连接选择 | Agent Center（智能体中心）保存 `connectionIds` 引用，独立于业务技能与人设 |
| 原生工具和生命周期 | 通过 `@paimind/harness-compat` 使用 `@deepseek-ai/dsh-mcp-client`，注册于目标原生智能体作用域 |
| 飞书命令转换 | 独立 `@paimind/feishu-cli-mcp`，官方协议库服务，固定本地账号配置，参数数组和标准输入调用命令行 |
| 业务技能资源 | `resources/business-skills/` 完整保留资源与来源；受管飞书入口明确对应四个原生工具，原入口保留于 `upstream/ORIGINAL.md` |

管理服务仅提供查询、保存、探测、启停、移除和模板，不提供工具执行接口。工具清单与运行、测试、业务调用证据来自当前宿主且不建立持久化影子注册表。测试连接只做协议握手与工具发现，不执行业务写入；身份检查也不计作文档操作证据。

传输支持 `stdio` 与 Streamable HTTP（流式网络传输），对应[官方传输规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)。具体兼容版本以[仓库兼容矩阵](../compatibility/matrix.md)为准，本次未升级宿主版本；适配器复用当前原生依赖图已选定的官方协议库 `1.30.0`。

飞书连接固定使用 `cli_aac6e775dc7a1cdc`，复用已有命令行授权。身份命令使用 `auth status --profile`，文档命令额外固定 `--as user`。连接配置、人设和技能未复制凭证；远程请求头及环境变量使用凭证引用，重新解析时检测轮换、撤销旧原生客户端，引用缺失时拒绝执行。
