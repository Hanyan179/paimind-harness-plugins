# 插件解耦与测试消息记录回归

日期：2026-09-07。Branch（分支）：`codex/plugin-bugfixes`，基于 `d7078f5`。

## 当前验收状态

根因修复尚未完成。以下测试与浏览器记录证明第一版实现的局部行为，不代表插件故障隔离与测试会话生命周期已经通过验收。

用户在上述限制已说明后要求合并当前版本。本次合并范围为已实现的插件缺席处理和只读测试历史入口，以下未完成项继续保留，不因合并改变验收结论。

- 可选来源未安装的触发条件已处理，但 `lifecycleStartupError` 仍是所有对话共用的启动门禁；可选来源的其他启动错误仍可能阻断无关对话。
- 测试会话不可打开的根因是智能体中心为隐藏普通侧栏条目而自动调用 `archiveSession`。切换测试、界面卸载和运行时重新加载都会触发归档；宿主会清空已归档会话的当前选择。第一版只读消息面板没有修正这个生命周期错误，不作为最终方案。
- 正确修复需要分离测试会话的用途分类、侧栏展示和归档生命周期，并保留原生会话打开路径。已被旧逻辑归档的历史需要单独处理恢复契约；当前固定宿主版本的公开工作区接口仅有归档操作，没有取消归档操作，不能以直接修改宿主内部存储替代该契约。

## 第一版实现与局部验证

- 技能中心仅在来源加载条目存在时默认启用 `genui`。来源缺席时保留已存启用偏好，但不执行该能力的生命周期，不阻断其他技能、普通对话或智能体对话。修改其他技能策略不要求补装缺席插件；新启用缺席能力仍被拒绝。
- 测试记录改为可点击、可键盘操作的按钮。历史读取通过原生 `session.history` 分页进行，校验记录属于当前智能体；不创建、重新绑定或取消归档历史会话。
- 原生宿主会清除已归档会话的当前选中状态，因此历史提供只读消息面板，并可返回当前测试。展示用户正文、助手正文、折叠工具记录和运行错误；按消息来源排除上下文注入，排除模型推理内容。
- 支持更早消息、读取失败重试和无消息提示。历史视图属于临时界面投影，不另存消息或增加执行接口。

## 真实浏览器验证

使用 `http://127.0.0.1:3086` 的独立宿主数据副本，插件链接到本分支。数据副本没有复制调度任务，未挂载、未安装 GenUI（生成式界面）来源插件，原有 `genui` 启用偏好仍为开启。

1. 普通原生会话发送独立测试指令，得到真实回复“普通对话验证通过。”
2. “飞书写作助手 0907”的原生测试发送独立测试指令，得到真实回复“智能体测试验证通过。”
3. 测试归档后，点击“运行智能体测试验证”记录，右侧准确显示该轮用户消息与助手回复。
4. 点击原有测试记录能读取原生消息及工具记录；页面不包含运行时上下文和技能目录注入。
5. 通过键盘打开空测试记录，显示“这条测试还没有消息。”；“返回当前测试”恢复原生测试输入区。

浏览器访问与截图证据保留在本任务。`3080` 仍是另一个工作树的运行实例，本次未替换其插件、配置或进程；本分支尚未合入该实例。
