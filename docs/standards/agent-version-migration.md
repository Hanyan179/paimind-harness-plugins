# 智能体创建、修改与会话迁移规范

## 创建与修改

1. 创建：原生复制基础 Preset，写入业务 Persona 和元数据，重新读取健康状态。
2. 修改：校验 `expectedVersion`，生成新配置版本，原子替换用户 Preset。
3. 已经开始运行的 Session 不更换 Preset generation（预设代际）。

## 旧会话迁移

打开已绑定旧版本的会话时：

1. 查询最新个人智能体版本。
2. 从旧 Session 只读取来源为用户的可见消息和助手最终消息。
3. 创建真实空白 Session，并在首轮前选择最新版 Preset。
4. 把摘要作为新版会话的可见首轮输入；不复制 Tool Call（工具调用）、Tool Result（工具结果）和内部提示。
5. 记录源会话、目标会话、旧版本、新版本和迁移时间。
6. 导航到目标会话并提示“已使用最新版智能体继续”。

已完成迁移的旧会话再次打开时直接导航到目标会话。摘要或新会话创建失败时，旧会话不变，也不发送任何待处理消息。
