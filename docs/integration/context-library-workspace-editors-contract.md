# 资料库与工作区内容集成契约

本契约对应 [实施方案](../plans/context-library-workspace-editors.md)，遵循 [插件规范](../standards/plugin-authoring.md)、[智能体与技能契约](agent-skill-harness-contract.md) 和 [工作区蓝图契约](workspace-blueprint-harness-contract.md)。

## 领域所有权

| 领域 | 唯一所有者 | 连接方式 |
| --- | --- | --- |
| 智能体身份、人设、配置 | agent-market | 公开资料查询；已保存详情通过 `paimind.agent.resources` 插槽接受资料界面 |
| 工作区、会话、工具执行、原生权限 | Harness（宿主） | harness-compat 从原生对象解析；不接受模型提供的调用者身份 |
| 模板文件夹、采用和组合回执 | workspace-blueprints | 增加三种模板；采用后创建原生入口会话，不复制授权 |
| 文档、幻灯片、表格的内容操作 | workspace-editors | `paimindWorkspaceEditors`；通过侧栏适配服务打开编辑页签 |
| 资料文件、连接和权限 | context-library | `paimindContextLibrary`；连接记录只存一份 |
| 原生工作区产品投影 | workspace-project | 继续保持只读，不反向依赖侧栏或编辑器 |

资料库属于独立功能包。编辑器属于内容工作区功能包中的可停用支撑能力。两者互不依赖；不新增产品总存储、影子会话或工具执行器。

## 公开边界

`ContextConnections` 处理连接查询、保存与解除；按目标或资料夹查询可以得到正向引用及反向使用位置。`ContextSessionResolver` 从可信宿主会话解析有效连接。`ContextAccess` 处理受限文件操作。浏览器管理操作使用严格远程描述，模型使用宿主工具；它们复用同一个资料库所有者。

`ContextIdentityProvider`、`ContextAuthorization`、`ContextStorage` 分别隔离身份、权限计算与存储效果，通过 `ContextLibraryOptions` 选择实现。首版存储接口要求文件系统语义及原子版本比较；未来对象存储实现需要提供等价事务适配，不能直接换成无版本覆盖。企业实现仍须遵守调用者身份及宿主权限上限。

连接目标只包含 `agent`、`workspace`、`session` 和真实稳定身份。智能体、工作区不维护资料编号数组；模型参数没有会话编号、工作区编号或绝对来源路径。未来定时任务只需创建合法宿主会话，不要求资料库理解任务业务类型。

## 授权与上下文

资料夹是连接与权限单位。默认只读；读写允许文件创建、更新、移动和回收。多个有效连接按正向授权合并，并保留来源；只读连接不会撤销另一条读写授权。企业策略可收紧有效权限。

每次工具调用验证真实宿主调用对象、会话归属、目标存在性、连接及路径。提交前再次检查身份及宿主文件权限，旧操作回执也必须先通过当前授权。资料连接不扩大宿主沙箱；资料库通常在工作区之外，受限会话的入库写入会明确拒绝，由用户在原生权限界面处理。

目录按当前会话提供；正文按需读取。资料库的 `SKILL.md` 只是普通文件。两个插件各自拥有一份源技能的摘要、正文、工具和生命周期；停用时一起撤销。技能目录在原生每步执行前失效刷新。

解除连接或降权约束后续访问，不撤回已进入历史消息的内容。首版本地权限约束插件接口，不提供操作系统进程隔离或员工隔离。

## 文件与事务

资料文件位于宿主数据目录下 `.paimind-context-library/collections/<id>`。元数据、连接、操作回执和回收记录由资料库保存。文件版本是原始字节摘要；文本分段保持字符边界；二进制内容以分段原始编码取得，不代表已解析正文。

写入要求预期版本，新建使用 `null`；替换使用临时文件、同步落盘和原子重命名。调用标识限定在真实会话或本地用户范围，同标识不同参数拒绝。操作回执记录调用、来源、时间及版本。准备记录支持提交前或文件提交后中断恢复；文件又发生无法解释的额外变化时返回 `RECOVERY_REQUIRED`，保留文件和事务记录，禁止静默覆盖。

工作区产物入库的来源只能是当前真实工作区中的相对路径，目标同时要求可写连接。路径拒绝绝对地址、上级跳转、符号链接和特殊文件。首版单文件最大 20 MB；每次读取最多 64 KiB；名称、说明、文本检索最多返回 100 个匹配。

三类内容唯一权威文件为工作区中带 `paimind.workspace-document/v1` 标识的 JSON（结构化数据）文件。编辑器列表按内容标识发现文件；原生普通 JSON（结构化数据）预览继续使用原有查看器，不抢占其扩展名。导出和操作回执属于派生内容，不作为编辑源。

文档已有块、表格单元格使用局部版本；新增、删除、排序、工作表结构和整份替换检查文件版本。结构修改刷新单元格版本，防止旧地址覆盖移动后的内容。写入先在事务副本中执行，任何局部冲突拒绝整批提交。工作区编辑回执保存在 `.paimind/workspace-editor-operations`，支持重启后去重。撤销历史保留在当前加载的模型中，重新打开或外部文件变化后重建，不承诺跨重启撤销。

浏览器未提交草稿保存在当前浏览器会话的暂存空间，内容文件仍是权威。外部修改在界面闲置时自动同步；存在草稿则保留并显示冲突，可下载当前或恢复出的草稿。暂存空间不足会明确提示。损坏文件报错，不初始化空白内容。

## 界面与生命周期

资料库提供文件夹浏览、上传、编辑、说明、搜索、下载、移动、回收和恢复。连接界面可从资料库、已保存智能体详情及会话资料页签进入。未保存智能体不建立连接。模板采用成功后发出 `paimind:workspace-adopted`，资料库贡献可选连接步骤，先通过公开目标查询确认真实工作区，再由用户明确选择授权；不选择时不建立连接。后续仍可在新工作区的资料页签配置授权，模板包不保存作者授权。该界面事件只用于展示，不能作为模型调用身份或授权凭据。

编辑器位于不共享宿主来源的隔离界面。受限桥接只绑定当前工作区文件和允许的方法；导入富文本清理危险内容。模板只复制内容，不执行任意脚本。编辑器通过现有侧栏适配器打开，并可进入专注编辑布局。

资料库停用撤销工具、技能和界面，保留资料与连接；编辑器停用保留全部工作区文件。重新启用重新解析真实目标，失效身份不会按名称自动重绑。三种旧模板的格式与已有组合回执不变。

## 首版导出和兼容范围

文档提供 Markdown（标记文本）、HTML（网页文档）和浏览器打印；幻灯片提供 HTML（网页文档）和浏览器打印；打印界面可另存 PDF（便携文档）。表格按工作表导出 CSV（逗号分隔文件），明确保留原始公式。公式引擎沿用固定参考源码，未承诺商业办公软件的完整公式兼容或办公文件双向无损转换。

不包含向量检索、扫描识别、企业员工权限、跨员工实时协作、定时任务改造或生产发布。
