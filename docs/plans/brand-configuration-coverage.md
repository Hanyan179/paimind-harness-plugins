# 品牌配置覆盖范围

本次为既有 `@hansen/branding` 增强，沿用原生 `hansen.branding` 设置，不新增插件或持久化仓库。

## 所有权与冲突评审

- 入口：品牌设置唯一拥有系统品牌配置；首页欢迎语只由品牌插件展示。
- 实体：系统显示身份；不改用户会话、智能体、工作区或提案模板的名称。
- 写入：品牌插件独占原生品牌命名空间；视觉插件不存第二份品牌状态。
- 运行时：使用已有设置服务；不新增运行时服务。
- 兼容：启动页定位、宿主标题和外观覆盖集中在兼容包。
- 卸载：客户端移除品牌样式、门户与设置订阅，恢复原生文档身份；启动注入随下一次页面加载消失。加载错误与进度始终由宿主管理。

## 覆盖清单

| 展示位置 | 配置与继承 |
| --- | --- |
| 展开/折叠侧栏、首页标志 | 品牌名称、主标志、可选深色标志；无图使用名称首字 |
| 首页欢迎语 | 中文/英文分别设置；空值隐藏；无重复视觉插件文案 |
| 启动页 | 共用名称与标志；不遮蔽加载状态或错误 |
| 浏览器标签 | 可选独立标题，默认品牌名称；保留会话标题前缀 |
| 浏览器图标 | 可选覆盖，默认主标志，再回退名称首字 |
| 安装应用清单 | 品牌全名、可选简称和品牌图标；已安装应用刷新依赖浏览器 |
| 首页背景 | 浅色/深色图片；深色未设则继承浅色；均空保留当前外观 |
| 主要操作/强调色 | 浅色/深色六位颜色值；均空保留当前外观 |
| 设置预览 | 跟随当前品牌与界面语言 |

提案模板里的客户品牌、模型供应商、第三方插件作者与技术诊断身份保持其真实来源。当前系统无品牌版权页脚或独立登录页，因此不添加无展示位置的配置。以后新增品牌展示位置须消费同一品牌配置。
