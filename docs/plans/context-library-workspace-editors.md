# 资料库与工作区编辑

状态：用户已授权实施；本文件记录所有权与交付边界，不代表验收通过。

## Ownership and conflict review

| 维度 | 决策 |
| --- | --- |
| 产品入口 | context-library 拥有资料库中心、会话资料面板及智能体扩展贡献；workspace-blueprints 保留模板入口；workspace-editors 通过侧栏适配器提供文件编辑器，不新增工作区中心 |
| 领域对象 | 资料夹、文件元数据、连接及权限由 context-library 唯一持有；连接选择位于使用方入口，资料库只读展示被谁使用；workspace-editors 只操作宿主已注册工作区的格式文件；宿主唯一拥有工作区和会话 |
| 可写状态 | 资料库受管文件及连接独立存储；智能体和工作区不增加资料编号列表；三类编辑器数据只在工作区文件中保存 |
| 运行时服务 | paimindContextLibrary 与 paimindWorkspaceEditors；资料解析按真实会话进行，不识别定时任务等入口类型 |
| 兼容性 | 所有宿主身份、权限和工具桥接放在 harness-compat；所有侧栏能力通过 better-sidebar-adapter |
| 失败与卸载 | 工具和界面随插件卸载，数据保留；资料庫停用不阻断无资料依赖的编辑；工作区投影不依赖新模块 |

## Reference and scope

参考 cloudflare/cloudflare-os b810d09f5358eeb4aeeef2acdde45aff54405277 的资料集合及三套编辑器。保存源码来源、摘要与 Apache-2.0 许可证。首版本地使用，身份、存储、授权均可替换；不修改定时任务插件，不提供企业员工隔离或多人实时协作。二进制存储不等同于正文提取。

## Contracts

连接目标是智能体、工作区或会话，资料夹级只读/读写授权由资料库持有。每次工具调用从宿主对象取得身份并复核权限；模型不能管理授权。写入执行版本比较、串行提交和调用去重。浏览器与模型使用同一个文件内容服务，未提交草稿不得覆盖外部修改。

## Acceptance

资料管理、三作用域连接、只读拒绝、授权写入、工作区文件入库、撤权、路径边界、取消、重复调用、重启及卸载。三编辑器采用、人工编辑、真实模型修改、版本冲突、导出与恢复。完成包、公开接口、类型、测试、构建、真实宿主组合和浏览器验证；证据与未完成项分别记录。
