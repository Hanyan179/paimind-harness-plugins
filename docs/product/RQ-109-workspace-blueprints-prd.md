# RQ-109 工作区模板中心

## 结论

工作区模板中心把专家已经编排好的文件夹、说明文件、交付物骨架以及可选的智能体与业务技能绑定，保存为可发现、可编辑、可版本化复用的工作区组合包。用户采用模板时复制的是一个可继续生产的半成品工作区；创建出的实例仍由 Harness 原生工作区与会话管理，模板中心不形成第二套运行时。

## 用户问题

企业用户每次创建项目工作区时，往往需要重复搭建目录、规范、输入区、交付区和执行配置。空白工作区保留了最大自由度，却无法复用成熟团队已经验证过的生产基座。现有工作区列表只表达正在使用的实例，也不适合承载可复用模板的编排、发现、版本和来源。

## 首版范围

- 提供独立的工作区模板中心入口，不改变原生工作区列表和会话列表。
- 提供三套内置、只读、带版本的纯文件夹模板：企业项目交付工作区、数据分析工作台、研究与决策简报工作区。
- 支持搜索、分类、模板详情、完整文件结构和确定的组合内容预览。
- 用户可以直接选择本地文件夹，或从一个 Harness 已注册工作区创建个人模板；两条入口都先取得 Harness 权威工作区身份，不把任意路径交给模板服务。文件夹内容是模板主体，智能体和业务技能绑定均为可选项。
- 个人模板支持查看、增加、修改和删除受管副本中的文件或子文件夹，并以摘要冲突检查保护并发保存。已发布版本不可变，每次编辑生成新的补丁版本。
- 用户明确选择一个空文件夹后，先由 Harness 注册原生工作区，再把选定版本物化到该工作区。
- 物化成功后创建并进入该工作区的新会话；模板声明的业务技能按精确摘要写入工作区组合回执并作用于该工作区会话，模板声明的智能体用于本次采用流程创建的入口会话。空组合则运行普通标准会话。
- 创建完成后用户直接维护独立文件副本；修改实例不会反向修改模板，修改模板也不会静默更新既有实例。

## 非范围

- 不把模板定义成智能体、技能、项目提示词或会话。
- 不复制或接管智能体中心、技能中心的实体存储；模板只保存这些对象的精确引用。
- 不把业务技能名称写入智能体人设，也不把模板绑定误写为个人默认技能。
- 不执行模板中的脚本、安装依赖或自动连接外部服务。
- 不在模板更新时静默修改已经创建的工作区。
- 首版不把个人模板发布到跨用户公共市场；共享、审核、权限和依赖分发进入后续版本。

## 核心对象

| 对象 | 唯一所有者 | 说明 |
| --- | --- | --- |
| 工作区模板 | `@hansen/workspace-blueprints` | 内置或个人的版本化文件夹快照与可选组合引用 |
| 个人模板仓库 | `@hansen/workspace-blueprints` | 用户模板的受管副本、文件编辑、版本和摘要冲突检查 |
| 工作区实例 | Harness | 用户选定的真实目录和原生工作区身份 |
| 会话 | Harness | 工作区创建成功后启动的原生会话 |
| 智能体绑定 | Agent Center | 模板仅保存精确 `agentId`、`presetId` 与 `configVersion` 引用；采用流程创建入口会话时调用公开契约绑定 |
| 业务技能绑定 | Skill Center | 模板仅保存名称与摘要；物化后的组合回执由 Skill Scope Resolver 按工作区解析，不修改个人默认、Session 临时选择或 Agent Profile |

## 主流程

1. 用户打开工作区模板中心，搜索或按分类找到模板。
2. 用户查看模板说明、完整目录、版本以及已经由模板作者确定的组合内容。
3. 模板服务通过两个来源中心的公开服务生成一次实时可选项投影，并预检所绑定智能体版本和业务技能摘要；缺失、停用或版本不一致时阻止创建并给出明确原因。投影只服务当前操作，不缓存或复制实体。
4. 用户点击“使用此模板”，通过 Harness 原生目录选择器选择一个空文件夹。
5. 客户端调用 Harness 原生工作区注册能力取得权威工作区身份。
6. 模板服务只根据该工作区身份反查权威目录，验证目录为空并执行受限物化。
7. 物化成功后创建原生入口 Session；若模板有 Agent 配置，则模板服务根据不可变模板与工作区组合回执重新取得精确引用，再委托 Agent Center 的公开服务绑定到该 Session。客户端不能替换 Agent 引用。Skill Center 根据已物化的工作区组合回执提供业务技能，随后进入真实对话。

个人模板创建流程为：选择本地文件夹并由 Harness 注册，或选择一个已经注册的 Harness 原生工作区作为文件夹来源；填写名称、版本与分类，按需选择一个已存在智能体和多个已安装业务技能，确认后将受限副本保存到个人模板仓库。个人模板后续可以在模板中心内编辑文件结构与文本内容；每次修改产生新的不可变补丁版本。所有绑定都是作者显式选择的确定配置，不存在“推荐能力”。

目录选择、原生注册和模板物化属于同一次不可重复提交。操作进行中，模板中心临时阻止关闭、切换其他产品中心和激活底层导航；操作完成或取消后立即恢复。若服务端返回清理警告，页面保留在当前模板并展示具体警告，只有用户再次确认“打开已创建的工作区”后才进入会话。

## 安全与失败边界

- 服务端不接受客户端传入的任意写入路径，只接受已经由 Harness 注册的工作区身份。
- 创建个人模板同样只从权威工作区身份读取文件，不接受任意来源路径；敏感文件、符号链接、设备文件和超限内容不会进入模板仓库。
- 未知工作区、非空目录、目录逃逸、绝对模板路径、符号链接、设备文件和超限内容全部拒绝。
- 模板内容先写入同目录临时区，验证完成后再提交；失败不得伪装成成功。
- 内置模板只读；个人模板文件修改使用 `expectedDigest` 乐观锁，冲突时必须刷新后重试，成功修改发布为新的补丁版本而不覆盖旧版本。
- 组合引用必须在保存和采用时分别校验；不得因名称相同而接受不同摘要或不同智能体版本。
- 工作区已经注册但后续流程失败时，保留原生工作区注册并明确说明“注册已保留、目录未自动删除”及具体原因；当前宿主创建接口不返回可原子确认的“本次新建”标记，因此插件不冒险删除注册，更不会删除用户目录。
- 工作区列表的加载状态与真实错误状态分别展示；注册表错误不得伪装成持续同步。
- 创建进行中不得因 Escape、底层导航或其他产品中心打开请求而卸载页面，避免后台写入完成但用户没有结果反馈。
- 关闭或卸载插件只移除模板中心入口与服务，不删除已经创建的工作区及其文件。

## 首版成功标准

- 用户能在真实 Harness 中打开模板中心、预览模板、从现有工作区创建并编辑个人模板，再创建一个真实工作区。
- 新工作区出现在原生工作区列表，首个会话可正常进入。
- 创建出的目录与模板清单一致，文件是可独立编辑的副本。
- 纯文件夹模板不要求智能体或业务技能；存在组合配置时，业务技能按工作区继承，入口 Session 精确绑定作者选定的智能体。
- 当前 Harness 尚无工作区默认 Preset 钩子，因此模板 Agent 不承诺自动覆盖该工作区后续由其他入口新建的 Session；界面必须明确这项边界。
- 模板绑定不会修改用户个人默认、Agent Profile 或其他 Session，也不会复制 Agent/Skill 实体。
- 取消、非空目录、非法路径和符号链接场景均无越界写入。
