# RQ-106 智能体中心产品需求

## 目标与边界

智能体中心是智能体的唯一业务入口；原 Agent Builder 不再提供独立页面，只作为后台工作流服务。DeepSeek Harness 继续拥有 Agent Preset（智能体预设）、真实会话、模型、工具和技能运行时。

## 页面

- `平台智能体`：展示标准、PTC、极简和创造四种 Harness 原生模式；普通用户只读，可开始真实对话。
- `我的智能体`：创建、编辑、删除、设为默认、开始真实对话。
- 未接入真实组织身份前，不展示组织智能体和组织权限。
- 设置导航不再单独显示 `Agent 构建器` 或 `Agent 预设`；原生 `Agent Presets` 通过智能体中心的 `高级配置` 打开。
- `创造模式` 只作为平台智能体开放，不进入个人智能体的基础模板下拉框。

## 业务字段

- 名称、描述、基础能力模板
- 角色、目标、行为规范
- 首选已安装技能
- 自然语言补充要求

`极简模式` 不加载 Skill；选择后禁用并清空首选技能，同时给出可理解的业务说明。标准和 PTC 模式可以选择已安装技能。

页面不显示 Preset ID、配置版本、会话 ID、文件路径、配置哈希或插件组合。

## 保存与运行

创建时先通过 Harness 原生接口复制基础模板，再由后台服务写入业务 Persona（角色设定）和元数据。保存后必须重新读取原生预设；缺失或损坏时不得标记成功。

`开始对话` 创建真实空白会话，在首轮前两次确认预设选择以跨过默认席位加载窗口，记录配置版本，并预填一个不重复配置的中性问题。用户决定是否发送。

## 版本迁移

每次保存产生新版本。新会话使用最新版；已运行会话不热切换。打开旧版会话时自动创建新版会话、写入只含可见人机消息的摘要、记录原会话关系并导航到新版。摘要失败时不发送、不改写旧会话。

## 验收

- 创建后真实首轮对话的预设、配置版本、用户问题和模型回复可核对。
- 设置中只有一个智能体业务入口；高级配置可以打开原生预设页，兼容层失效时原生入口保持可见。
- 平台智能体包含 Harness 返回的 `cordis` 创造模式，但个人模板不包含它。
- 修改后新会话使用新版本；旧会话打开后迁移并保留原历史。
- 技能缺失、预设损坏、模型失败或版本不一致时不标记验证通过。
