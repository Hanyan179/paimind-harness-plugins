# 资料库与可编辑工作区

资料库存放可长期复用的文件，工作区存放正在完成的任务与产物。智能体、工作区和当前会话可以引用同一份资料；权限在连接时配置，文件不重复复制。

## 资料使用流程

1. 从资源导航进入“资料”，新建资料夹并说明用途。
2. 上传文件或文件夹，也可以直接新建和编辑文本。文件可移动、下载、回收和恢复。
3. 在“连接位置”、已保存智能体详情或会话的“资料”页签中，选择未连接、只读或读写。
4. 发起任务。模型通过资料工具查看目录、检索和按需读取；具有读写授权时可以更新文件或将当前工作区产物入库。

“当前会话的资料”展示合并后的权限及所有来源。同一资料夹只列一次；如果工作区是只读而智能体是读写，最终仍为读写。要撤销写权限，需要移除全部写入授权来源。

宿主文件权限仍然生效。只给资料连接授予读写，不一定足以写入宿主工作区之外的目录；被宿主拒绝时，界面与工具会说明原因。模型不能自行修改资料连接或提升权限。

## 三种工作区

从资源导航进入“模板”，选择文档、幻灯片或表格工作区，指定空文件夹后采用。系统创建原生工作区及入口会话，打开“编辑”页签。可点击“专注编辑”展开画布。

采用成功后，资料库提供可选的“连接工作区资料”步骤。新工作区默认不连接任何资料，用户选择只读或读写后立即保存；也可直接继续工作，稍后从会话资料页签配置。此步骤只为已经创建的真实工作区保存连接，不把授权写入模板。

| 类型 | 可以做什么 | 导出 |
| --- | --- | --- |
| 文档 | 标题、段落、列表、链接、图片和块级内容编辑 | 标记文本、网页、打印另存便携文档 |
| 幻灯片 | 页面顺序、组件、布局、属性、拖动缩放、撤销和演示 | 网页、打印另存便携文档 |
| 表格 | 多工作表、单元格、公式、格式、排序和行列操作 | 每张工作表的逗号分隔文件，保留公式 |

用户和模型修改同一份工作文件。保存完成后可以刷新、关闭或重启宿主，再次打开继续编辑。已有办公生成及产物查看功能继续保留。

## 修改冲突和恢复

保存时检查版本，防止后台模型覆盖用户修改。不同文档块或单元格可以独立提交；同一位置发生冲突会提示，并保留未提交草稿。先下载草稿，再重新打开最新保存版本进行合并。表格中的尚未提交输入也随草稿保留。

文件损坏时显示错误，系统不会用空白文档覆盖。浏览器暂存空间不足会提示下载草稿。回收区保留已回收内容，可恢复到原位置；原位置已占用时拒绝覆盖。

## 当前范围

本地使用，单文件最大 20 MB。搜索覆盖文件名称、说明及文本正文；保存二进制文件不代表已完成正文解析。没有向量检索、扫描识别、员工权限管理或实时多人协作。表格保留参考公式能力，不承诺商业办公软件完整兼容；三种编辑器也不承诺办公文件无损往返转换。
