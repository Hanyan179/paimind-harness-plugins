# 智能体与 Skill 故障排查和验收手册

## Skill

| 现象 | 检查 | 处理 |
|---|---|---|
| 上传失败 | 文件名、请求中断、临时磁盘 | 重新选择；临时文件会清理 |
| 检查拒绝 | 路径、链接、加密、压缩比 | 修复包结构后重新上传 |
| 安装失败 | 可用磁盘、同名目录、摘要变化 | 原版本自动恢复；重新检查 |
| 安装后未发现 | 当前 Session/Preset 是否组成文件系统 Skill provider | 新建真实会话并刷新目录 |
| 无法卸载 | 是否由 PAIMind 管理 | 手工 Skill 继续由原维护者管理 |

## 智能体

| 现象 | 检查 | 处理 |
|---|---|---|
| 保存失败 | 基础 Preset、用户根可写、版本冲突 | 刷新后重试；失败不覆盖旧配置 |
| 开始对话失败 | 新会话是否空白、Preset 是否健康 | 修复原生 Preset 后重试 |
| 回复未体现配置 | 会话头部 Preset、绑定版本、首轮是否真实完成 | 不以文本碰巧匹配代替绑定校验 |
| 旧会话未迁移 | 是否有新版本、摘要能否读取 | 重开旧会话；失败时从最新版开始空白对话 |

## 3080 验收清单

1. 本地导入安全 Skill，确认风险预览、安装、无需重启发现、真实调用、更新、卸载。
2. 创建带明确回复前缀和结构规则的个人智能体，保存后重新读取为健康。
3. 点击开始对话，检查会话头部绑定，发送中性问题并核对真实回复。
4. 修改行为规范，再开始新对话，确认新版本生效。
5. 打开旧对话，确认自动迁移、可见摘要、原会话引用和自动导航。
6. 检查页面没有内部 ID、路径、哈希和 `e2e` 数据；检查桌面和窄屏。
7. 执行测试、类型检查、生产构建、框架检查和文档链接检查。
