# 发布准备与未解决项

本文件是检查清单，不是发布批准、许可证或新的验收结果。仓库已公开这一事实不使以下项目自动通过。

## 当前必须单独解决

- [ ] 确认项目级许可及各包 `UNLICENSED` 声明的适用范围
- [ ] 对内部技能与受限参考代码取得可核查再分发许可，或由权利人确认替换/移除方案
- [ ] 核验导入技能的精确来源、版本、版权、许可和改写范围
- [ ] 核验品牌、人物/图像、业务故事板和截图的公开权利
- [ ] 检查所有拟公开 refs 和 Git 历史中的个人路径、秘密、内部资料及测试产物
- [ ] 确定专用私密安全/行为报告渠道与维护责任
- [ ] 在最终代码上完成真实安装、组合、浏览器和失败恢复验证
- [ ] 核实 npm/发行包的实际内容、版本与发布权限；不能仅凭 `files` 配置或包命名判断已发布

## 证据记录

对每项记录责任人、范围、版本/SHA、核对时间、证据及结论。授权证据应保存在有权限的私密位置；公开文档只保留必要的范围说明，不上传合同、私人资料或真实凭据。

[第三方说明](../../THIRD_PARTY_NOTICES.md) 列出当前可从仓库材料确认的边界。既有内部许可与来源说明保持原样，不通过新增一个根许可证将其覆盖。

本轮不改可见性、历史、代码或发布设置，也不删除受限材料。未解决项仅阻止相应授权/发布步骤，不阻止修正文档事实。
