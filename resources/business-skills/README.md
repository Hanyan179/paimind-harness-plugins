# Writing acceptance Business Skills

These are complete user-installable skill packages, not System Skills and not automatic global registrations. Install each folder or a ZIP containing its files through Skill Center, then explicitly select it in the target Agent.

- `human-writing`: original entry, references and scripts preserved byte for byte; `PROVENANCE.json` records source digests.
- `lark-doc`: complete document references, managed four-tool mapping, original entry retained as `upstream/ORIGINAL.md`.
- `lark-shared`: managed identity/permission rules with the original entry preserved.

Each archive has exactly one `SKILL.md`. Source CLI commands remain as reference material; the managed entry requires the currently bound native MCP tools and does not start another CLI or change a global account. Source provenance is local import evidence, not a claim of an upstream release.
