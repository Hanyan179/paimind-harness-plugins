## Responsibility

连接器当前权限复用同一反向私有通道。`connector.approval` 只返回当前准确批准修订，不是登录或工具许可；`connector.authorize` 还在同一租户撤权事务中验证签名登录／会话来源、原智能体及技能发布权限。二者都核对准确成员、稳定配置版本、服务名、传输、持久单元／卷／镜像／策略和当前运行修订／容器／租约，并拒绝同成员未确认配置命令。固定完整单元身份的原启动／替换闭包在异步回读前后复核，调用方不能自报租户、成员或地址；通道断开、取消、格式错误或旧批准修订均拒绝，无上次成功回退。这是内部当前核验，不是公共命令、持久许可或原生工具来源证明。受管原生组合已用原配置所有者、准确注册对象及当前活动轮次接入启停依赖生命周期、有限续验与实际调用前后核验；没有该完整组合仍拒绝连接器使用。网关启动及准确替代单元发布后，私有 `connector.restore` 仅重新验证已保存启用意图，区分已观察的恢复／待定与未知回执，不自动重发。管理员持久启停命令、启用配置管理及原设置界面尚待接通；最终成套镜像、双容器和浏览器验收未完成。

既有私有原生控制通道提供 `feature.describe`、`feature.plan`、`feature.apply` 三项准确操作，分别调用原扩展中心内部回读、计划及命令执行。传输只检查有界结构，原所有者再校验准确目录、完整影响、命令及批准集合；没有通用加载器接口、任意地址、身份或文件选择。企业管理员批准／目标权限／持久审计由上述控制面负责，不能把私有传输密钥视为管理员许可。超时或取消只能报告结果未确认，不自动重复、修复或回退已接收的原生副作用。必须完成管理绕过限制及成套镜像／原界面验收后才能用于在线环境。

技能内容读取新增精确发布／修订／归档摘要绑定的 `content/.../entries/{cursor}` 和 `content/.../files/{index}/{offset}` 路由，管理员审核与成员获配两个命名空间分别授权。控制面从既有不可变数据库分块随机读取，不访问当前可编辑源、不解压落盘、不建立副本或缓存权限；每次数据库分块与返回前重新核对准确登录、修订及当前分配。每次最多100条目录或32KiB文件字节，保留空目录／空文件、二进制及全部分页；只接受原来源所有者使用的不压缩归档格式。每账户最多2个、服务最多8个同时读取；内容处理有30秒取消信号，数据库认证可用性仍受原事务／连接边界约束。原归档摘要在捕获封存时已核对；读取信任数据库对已封存分块的不可变约束，不声称每个小文件请求重新哈希整个归档。读取不是安装、启用或执行许可，浏览器仍须独立验收。

技能归档使用显式迁移 `0007-skill-publications.sql`，不会由服务器自动更新在线数据库。`/haas/v1/admin/skill-publications` 提交／列出管理员本人固定技能版本；编号下的读取、`review`、`assignments` 分别管理审核元数据和分配。`/haas/v1/catalog/skills` 仅返回当前明确获配的已发布摘要，不返回归档字节，不提供安装或运行许可。技能版本由原技能中心私有导出，控制面按96KiB分块保存，最大200MiB展开／216MiB归档，每租户最多1000候选与2GiB归档容量；在途捕获按最大包预留。大包传输不持有身份事务锁，末尾重新认证并与命令回执、成功审计原子提交。相同请求重试保留已封存内容；失败只清理准确未封存捕获代次，数据库结果不确定时不推测删除。过期半成品只在明确重试原请求时恢复，没有后台清理或定时任务。

数据库封存与发布身份不可变，分配沿用用户显式拒绝优先的策略。原智能体发布表与运行门禁保持；技能归档审核完整界面和真实运行验收仍未完成，不能将管理接口或归档成功当作真实前端验收。应用角色仅获归档插入、捕获／封存字段更新、暂存块插入／删除、发布插入及审核字段更新和技能分配读写；没有删除封存或发布历史、修改审计及DDL权限。精确授权见新建隔离夹具脚本，生产迁移须另行验收。

`POST /haas/v1/catalog/skills/{publicationId}/adoption` 通过当前成员准确私有运行单元，把完整封存包交给原技能中心采用。请求只接受预期修订与摘要；管理员和作者也须明确获配。每个分块与最终回执重新检查准确登录、版本及当前分配，不长期持有身份锁。原所有者验证归档和完整目录摘要，在既有安装回执保存不可变企业来源；保留名称，同名个人内容或其他发布版本拒绝覆盖。已提交请求重放只重新授权和回读原生完整内容，不重传或修复。原生落盘后若失去确认、授权或审计提交失败，保留历史内容并用原键重试；文件与数据库不是分布式原子事务。采用响应明确 `runtimeGrant: false`，本地用户偏好不能启用该企业版本；当前运行授权、完整界面和真实双运行单元／浏览器验收仍为待完成。

版本化 `/haas/v1` 接口。独立工作台已按用户纠正撤回；管理界面由 `@paimind/enterprise-admin` 贡献到宿主设置。

成员组接口由同一身份模块拥有：管理员创建、完整编辑名称和成员、归档／恢复；成员不能查看或写入管理接口。迁移 `0005-member-groups.sql` 增加租户复合外键、组版本及名称约束，不新增角色或原生资源副本。应用数据库角色只需对 `member_groups` 的读取／新增／更新与 `group_members` 的读取／新增／删除；不能删除组或修改审计。迁移与权限须由明确隔离环境的操作者应用，服务器不自动迁移任何数据库。缺少表时失败而非回退为空列表；现有在线实例不会因源码改变被自动重启。分组不等于资源授权，后续发布、策略解析与运行撤销仍未完成。

完整成员组编辑的请求体上限为32 KiB，以容纳500个规范UUID及名称／版本。其他身份命令和组状态命令仍为16 KiB；超限返回413且不进入状态修改。字段、成员数量、身份和版本校验不因传输上限改变而放宽。

智能体发布使用迁移 `0006-agent-publications.sql`：来源配置的准确版本只从服务器绑定的本人原生单元读取，控制面持有不可变业务快照，不复制个人创建会话或原生历史。数据库禁止应用修改发布内容、删除发布记录；审核状态、分配、幂等回执和审计在同一事务提交。应用角色新增发布表的插入权限及仅状态／修订／审核字段的更新权限，分配表只读／新增／更新；迁移仍须由操作者明确应用，不能自动修改在线数据库。

`GET /haas/v1/publications` 只列本人提交记录，`GET /haas/v1/admin/publications` 为管理员审核清单；`GET /haas/v1/catalog/agents` 列当前明确分配的已发布内容，三者不互相冒充。`POST /haas/v1/publications` 只能提交本人已保存智能体的准确版本进入待审核，不能提交内容或指定身份。管理员通过发布编号下的 `review` 和 `assignments` 子路径审核／撤回及维护分配，后者支持只读回读。所有启用路径及严格输入／返回结构见[接口契约](../../docs/api/haas-v1.openapi.json)。

有效分配逐次重读：用户显式拒绝优先于用户允许、有效组允许和全员允许，缺省拒绝；组归档／退出、成员停用和会话失效即时影响后续读取。只有具体用户支持显式拒绝。本人或管理员的 `review-copy` 是审核副本，不赋予成员采用或运行权；作者身份也不会自动加入企业分配目录。带业务技能依赖的智能体在批准时必须明确选择已发布且完整目录摘要相同的技能编号；缺少或不匹配仍拒绝。最终原生资源采用、撤销后的运行、历史只读和真实浏览器组合验收仍未完成，不能以控制面接口通过代替。

迁移 `0008-agent-skill-dependencies.sql` 新增仅由智能体治理拥有的不可变依赖关系。审核请求的可选 `skillPublications: [{name, publicationId}]` 仅允许用于批准，必须完整覆盖原快照的依赖，不允许重复或额外项；关系、审核状态、命令回执及成功审计同一事务提交。数据库拒绝错误版本、已发布后的新增关系、修改／删除和缺少依赖的发布；旧快照与采用回执不改写。应用角色只获得新关系表读取和插入权限，不自动迁移在线库。

详情的 `skillPublications` 展示固定编号和当前技能状态，不是第二份技能目录或权限。成员读取已分配内容、采用及运行分别核对技能的当前分配；智能体分配不自动添加技能权限。同名同摘要的另一个技能发布不能替代已审核编号。网关沿原私有 `skill.adopt.receipt` 在原生智能体采用前后核对准确已安装版本，不自动安装／启用／覆盖技能，也不把治理关系写入宿主配置。来源许可或采用失败保留既有字节与历史，不能宣称未发生任何本地写入。

显式配置 `loopbackDevelopment` 与 `nativeDevelopmentOrigins` 时，开发网关根据服务端身份和数据库绑定转发真实宿主原始页面、资源、HTTP 调用和两条下行事件通道。原生版本相关路径只由 `@paimind/harness-compat/gateway-transport` 定义。未配置时保持仅提供控制面接口，不开放匿名宿主代理。

管理员的开发进程与成员的受管容器是两条独立准入路径。迁移 `0004-managed-runtime-cells.sql` 为成员绑定记录不可变容器、镜像、独占卷和策略摘要；它必须与私有启动配置 `nativePrivateCells` 中的独立操作者快照逐字段一致，并且只能使用对应的私有连接通道。开发进程仍仅限管理员，不能靠添加一个地址开放给成员。两个真实成员已进入原生浏览器切片，但完整成员流程、最终镜像和正式入口仍未验收，不能当作完整企业产品。

网关的角色操作门禁已经接入真实身份和审计：每次转发前重新核对租户、用户和角色；成员只允许明确列出的原生使用操作及个人智能体操作，企业智能体发布、平台设置、凭证和技能创作仍拒绝。智能体保存须是 `standard` 个人预设；请求头和请求内容不能提升角色。拒绝操作有数据库审计，审计不可用时返回503且不转发。鉴权等待计入原租约，不能延长授权有效期。此门禁不替代对象所有权、企业分配资源保护和运行内部工具隔离；生产成员准入拒绝条件仍保留，测试中的显式合成运行授权不得用于部署。

`node scripts/enterprise/start-member-acceptance.mjs <private-configuration>` 只用于当前隔离交付环境中已通过页面创建的 Hansen／Alex。独立操作者进程先验证真实镜像、非管理员容器、只读根、固定策略、专用卷与网络、私有连接和原生工具策略，然后通过 `RuntimeAdmission` 签发30秒绑定租约；运行期间回读并续租，网关没有引擎或数据库所有者凭证。成员失效或单元故障只撤回该成员；控制器结束先暂停绑定再停止其精确容器，保留数据和审计。`resumeStatePath` 只接受已有关闭回执、无卷使用者、同一成员及数据身份的暂停单元，实际启动替代容器后以新修订号原子替换，不复活过期租约或覆盖其他维护操作。这个部署进程不创建定时任务。

当前成员镜像迭代只更新明确列出的部署文件，并保留完整基础镜像来源；它不重新构建变更后的产品包，也不等于最终镜像验收。出站规则、控制器异常退出时原生在途执行的完整撤销、成员工作区选择、角色可见入口和模型真实回复均须继续正式验收。浏览器已发现的失败见[检查点](../../docs/checkpoints/enterprise-haas.md)，不能通过放开全文件系统浏览、平台配置或动态插件执行来消除403。

## Lifecycle and failure

只运行于明确指定的独立环境。关闭需断开本网关连接、等待请求、关闭数据库连接；身份、审计和依赖失败时拒绝写入，不回退到内存权限。

`haas.runtime_bindings` 只记录运行单元选择与租约，不拥有原生对象；应用数据库角色仅能读取，部署侧登记真实绑定。浏览器不提交目标地址。绑定必须同时匹配当前租户、用户、登录会话和操作员独立允许列表；禁止共享 `3080`、网关自身、非回环地址或路径。当前 `development-process` 明确不是容器安全证明。

迁移 `0003-runtime-maintenance.sql` 增加仅操作者可写的维护回执。内部 `RuntimeMaintenance` 在同一事务提交绑定暂停、新修订号、到期租约、幂等回执和成功审计，然后才允许调用方停止旧单元或维护存储。相同请求重放必须仍匹配实际暂停绑定；其他主体、变化输入或已被替代的修订拒绝。应用角色不能伪造该维护回执，不能借用它自己可写的普通用户命令回执绕过门禁。失败保持暂停，成功维护也不自动恢复旧租约；重新开放需要独立的新运行准入。

原生操作授权可能等待策略或审计，因此网关在真正转发前再次回读完整绑定并比较修订，仍以原授权截止时间为上限。此检查拒绝授权等待期间已发生的暂停／换绑定，不声称能撤销已经发送的副作用；维护仍必须真正终止并加入旧写入者。

`node scripts/enterprise/maintain-bound-storage.mjs <private-configuration>` 是隔离交付环境的显式操作者命令，不是浏览器接口。私有配置包含 `databaseConfigPath`、完整维护 `request`、`oldContainerId`（已移除时为 `null`）及 `storage`（精确卷、镜像、策略路径和所有权标签）。`io.paimind.runtime-cell` 必须匹配目标绑定，已存在容器须通过精确编号／镜像／标签／挂载回查；先提交暂停，再停止并移除旧容器，最后调用已验证的离线维护控制器。命令不删除卷、不重启单元、不开放成员权限，不接受生产数据库或共享3080。操作凭证只由独立进程读取，不进入网关配置或工作单元。

转发不携带登录 Cookie、外部身份头或转发头，也不接受上游设置 Cookie、重定向或覆盖网关安全策略。长连接串行回读身份和绑定，默认每 2 秒验证，验证挂起另有 2 秒硬截止及独立过期计时；撤销、变更、过期或依赖失败均断开。当前开发载荷上限为 HTTP 请求 8 MiB、事件消息 16 MiB，完整附件／负载验收仍待进行。登录替换同一浏览器已有 Cookie 时撤销旧会话，保留其他设备会话；浏览器账户切换后原生内存界面的清除仍须交互验证。
