# SOL 有效商品目录工作流

此示例组合已有插件，在本地工作区生成自包含 HTML（网页）目录，再通过当前会话的资料工具原子更新资料库。它没有独立调度器、模型客户端、MCP（模型上下文协议）注册表或资料连接状态。

用户配置的飞书来源只读。`SOL` 的 `Item Status` 精确等于 `ACTIVE` 才进入目录，顺序沿用完整表格快照。只按去除首尾空格的 `ITEM#` 精确关联同一表格空间中 `Artwork & Sample Tracker` 的 `PRD Render Image`，不做模糊匹配、不取其他图片字段。页面使用稳定的来源记录身份；缺商品编号、名称、正文值或图片不会丢弃该记录。图片超过四张或关联不唯一时报告需处理。

保留原始字段。金额沿用美元显示，IMU（初始加价率）显示整数百分比，颜色按未四舍五入的实际值判断，低于 60% 红色、达到 60% 绿色；无法解析不猜测。原图保留在工作区，网页展示副本使用同一比例压缩，没有裁切。原始文件和展示副本均保留摘要。参考布局、来源摘要与内部采用许可边界见 [来源记录](provenance.json)。

## 配置

从仓库安装依赖并构建后，使用宿主公开接口创建真实工作区、保存基于 `standard` 的飞书商品目录助手，安装此目录的薄业务 `SKILL.md`，在技能中心启用并绑定该助手。业务逻辑在程序里，技能只维护调用顺序。

创建单独的飞书只读连接，复用已授权的本地 CLI（命令行工具）账号配置；服务命令使用 `packages/feishu-cli-mcp/lib/server.js`，显式指定 `--cli`、`--profile`、`--export-root`、`--base-token`、`--table-ids`、`--read-only`。导出根目录就是该工作区，表格范围只包含已选择的两张表。与其他飞书连接相互独立。

工作区 `sol-sync.json` 包含 `baseToken`、`solTableId`、`trackerTableId`、`collectionId`，不含凭证。`sync.mjs` 仅导入本目录 `run.mjs` 的 `execute`，将当前工作目录、命令与参数交给它。部署时生成绝对入口地址，不复制一套业务程序。工作区读写连接到专属资料夹；其他智能体按需自行选择资料连接。

复用 `paimind:agent-prompt` 定时动作，配置真实工作区目录与助手预设。先暂停创建并手动运行，再按用户确认的 `Asia/Shanghai` 每天 `09:00` 启用。任务说明仅要求加载本业务技能并执行同步，不复制流程正文。

## 文件与一致性

- `runs/<运行编号>/` 保存本次完整来源快照、确定性计划、附件请求与结果。
- `originals/` 保存仅由飞书工具下载的产品图；每次使用都校验来源与字节摘要，损坏不当作缺图片。
- `candidates/<内容摘要>/catalog.html` 是待发布文件，重试保留首次生成时间，源数据不变时字节不变。
- 资料夹的 `catalog.html` 是唯一当前产物。开头的 `catalog-facts` 包含全部事实、来源记录、页码与图片摘要，便于模型分段访问，后面才是展示图片。

每次运行首先通过原生资料工具读取目标版本，然后才取来源。发布使用这个版本做比较与交换；冲突不重试覆盖。只有原生入库成功且回读版本相符才报告成功。没有变化时重新读取来源、校验缓存并比对目标版本，不改写目录。中断可重试，候选与其生成时间均原子保存；失败保留上次产物。

资料连接的读写权限与宿主文件权限分别检查；本工作流不绕过宿主权限。用户明确授权后，可在该任务的 `actionInput.permissionPreset` 保存 `danger-full-access`；适配器只在该任务新建会话、首轮运行前，通过原生 `permissionPresets.set` 应用权限。未设置时沿用宿主默认值，缺少原生权限服务时失败关闭。普通对话与其他任务不变；模型的 `schedule_manage` 创建参数不能增加此权限。任务详情和编辑页面显示已配置的权限。宿主只允许工作区内写入而资料库位于外部时，入库明确拒绝，任务保持需处理，不声明已发布。运行环境关闭时不会后台唤醒电脑。

## 验证

运行本目录的测试、飞书适配器测试与全仓库检查。真实验收应分别记录：完整分页读取、附件来源、68 条当前实际有效记录（快照数量，不是固定代码约束）、无图页面、IMU 阈值、版本冲突、重复运行不写入、资料工具回读和独立只读会话引用。HTML（网页）验收不代表 PPTX（演示文稿）导出验收。

## 本次公开契约评审

飞书适配器保留原有四种操作，增加两种结构化 Base（多维表）操作及可选来源/输出范围。新的内部导出模块随服务打包。调度器宿主适配增加可选的原生权限选择与原生工作区登记：以新会话的真实目录匹配现有工作区，通过其 `attachSession` 完成归属，登记失败则释放会话并停止。普通非工作区任务不变。调度界面仅展示任务已配置的文件权限，其客户端发布文件摘要随本次变更更新。没有新增产品入口、持久化命名空间或资料编号列表；受影响的公开声明摘要仅在此项增量评审后更新。
